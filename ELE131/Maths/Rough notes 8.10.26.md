


A point on the unit circle corresponding to an angle $\theta$ has coordinates ($cos{\theta}, sin{\theta}$).

The smallest positive repeat interval of a function is called the **period**.

The formula $\omega=2\pi f$ shows the angular frequency of a sinusoidal signal with frequency $f$ (i.e. what distance along the unit circle would it cover. Measured in radians per second). 

If a function is periodic then $f(x+T)=f(x)$ for some non-zero $T$. Where T is the period

For a signal modelled by trigonometric function $y=Asin{(Bx+C)}+D$,
- A changes the amplitude
- B changes the period
- C changes the phase shift
- D changes the vertical shift

For this function, the period is $T=\frac{2\pi}{|B|}$. For functions based on tan, $T=\frac{\pi}{|B|}$ as the period for tan is $\pi$ instead of $2\pi$.

The frequency of a function can be found with $f=\frac{1}{T}$.

e.g. if $v(t)=5sin{(200\pi t)}$:
- $\omega=200\pi$
- $f=\frac{\omega}{2\pi}=\frac{200\pi}{2\pi}=100$
- $f=100\text{Hz}$





Remember that $sin{(-x)}=-sin{x}$ and $cos{(-x)=cos{x}}$. I.e. $cos{x}$ is an even function as it is symmetrical across x=0
- Even functions are functions where $f(x)=f(-x)$
- Odd functions are functions where $f(-x)=-f(x)$ (symmetrical to the origin instead of the y axis)

Trig functions scale infinitely, e.g. $sin{x}=\frac{1}{2}$ gives solutions $x=\frac{\pi}{6}+2k\pi$ and $x=\frac{5\pi}{6}+2k\pi$ where $k\in\mathbb{Z}$. This can be used to give solutions in multiple quadrants of the unit circle.
